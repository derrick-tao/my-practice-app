## Running tests (agents)

Seam 1 e2e runs WebKit browsers; running it carelessly, or from several agents at once, exhausts the machine.

- While iterating, run only the relevant spec files: `npx playwright test tests/e2e/<file>.spec.ts`. Local runs are capped at 2 workers by `playwright.config.ts`; don't raise it.
- Run one Playwright pass at a time. Give each agent or worktree its own ports so servers don't collide: `E2E_FIXTURE_PORT=<n> E2E_REAL_PORT=<m>` (defaults 4173/4174).
- Don't run the whole e2e suite locally (`npm run test:e2e`, `npm run check`) unless asked; CI runs it sharded on every PR.
- Seam 2 content tests (`npm run test:content`) and `npx tsc --noEmit` are cheap; run them freely.
- A fresh worktree needs `npm ci` and has no `.env`: set `FAKE_AUDIO=1`. Real phrase audio is generated by the deploy workflow on main.

## Release log

A PR that makes a change a grown-up or learner would notice adds its own entry at the top of `content/releases.json` (date, short title, 1-4 plain bullets using the child-facing names); chore, CI and audio-regeneration PRs add none.
